# BinanceQuant

Downstream single repository (per Team C D1) consuming `BinanceMarketDataContracts`, `BinanceMarketDataRecorder`, and `BinanceMarketDataGateway` (`127.0.0.1:50051`).

## Packages
- `bq_nautilus`: Active **NautilusTrader (`2.0.0rc9` / candidate `2.0.0rc9+bmd2`, Python 3.13 `uv`)** thin adapter & validation layer (`M-NT1`–`M-NT4` delivered 2026-11-27, including Team C P1 fixes, `v2.0.0rc9-bmd2` Release CI, 35/35 dual-market full-stream parity, and frozen zero-credential 72h Sandbox):
  - `mnt4_risk.py`: Single-keyed non-blocking OS lock (`SingleKeyedProcessLock`), SQLite WAL UTC daily-loss/kill-switch ledger bound to `(environment, account_id, trader_id)` (`PersistentUtcRiskStateStore`), synchronous pre-trade `SUBMIT`/`MODIFY`/`CANCEL` gate (`SynchronousRiskGate` & `RiskGuardedStrategyMixin`, keeping `CANCEL` and `reduce_only` exits open during lock), plus native `LiveRiskEngineConfig`/`LiveExecutionEngineConfig` builders.
  - `mnt4_simulation.py`: `BookType.L2_MBP` simulation (`liquidity_consumption=True`, `bar_execution=False`) with 3-stage latency, same-level contention, shallow-depth partial fills, price-jump misses, fast-vs-slow cancel race, Spot proxy latency sweep, and `MAKER_QUEUE_BOUNDARY_NOTICE` passive bounds.
  - `mnt4_recovery.py`: Spot Testnet & USD-M Demo fault-recovery suite (`FaultInjectingSpotExchange`, `reconcile_with_transient_guard`, HTTP 504 drop-ACK quarantine, transient `-2013` freeze, cross-symbol `trade_id` separation, restart cleanup, and `audit_credential_and_host_boundary`).
  - `mnt4_sandbox.py`: Zero-credential `LiveNode(Environment.SANDBOX)` runner (`SandboxHourlyAuditStrategy`), hourly UTC sanitized event archiving & audit sealing (`HourlySanitizedWriter`), and bit-exact offline `BacktestEngine` replay auditor (`replay_sealed_hour`), executed via `scripts/mnt4_sandbox_72h.py` & `scripts/mnt4_verify.py`.
  - `instruments.py`: D4-compliant contemporaneous Spot (`CurrencyPair`) & USD-M (`CryptoPerpetual`) instrument builders from `ReferenceObservationEvent` / `exchangeInfo` (5 BMD symbols, `LOT_SIZE`/`MARKET_LOT_SIZE`, `maintMarginPercent`/`requiredMarginPercent`, `LeverageBracketTier` & `compute_tiered_maintenance_margin`).
  - `usdm_accounting.py`: Strict `Decimal` single-symbol, one-way (`BOTH`), isolated-margin USD-M ledger (`IsolatedUsdmLedger`), risk/margin/reduce-only/closePosition planning (`plan_usdm_isolated_order`, bypassing opening budgets for valid exits & never clamping below `MIN_NOTIONAL`), chronological fill-history boundary funding + cross-before-isolated settlement, atomic `apply_fill` with `fill_id` dedup, pre/post liquidation snapshots, and `BinanceTieredMarginModel`.
  - `usdm_runner.py`: Nautilus USD-M perpetual audit strategy/runner (`UsdmPerpAuditStrategy` with reversal/cache protection lifecycle, fill dedup & unconfirmed-protection risk blocking; `run_usdm_backtest`), Demo config builder (`build_binance_usdm_demo_configs`), and `SignedUsdmRestClient` + offline-default `scripts/mnt3_usdm_verify.py`.
  - `custom_data.py`: `CustomData` datatypes/payloads for sparse `liquidation` (`BmdLiquidationData` with explicit throttled sampling note), `reference_data` (`BmdReferenceData`), isolated cross-asset factor quotes (`BmdFactorQuoteData`), and per-stream feed quality (`BmdStreamQualityData`, decoupled from exchange-wide `InstrumentStatus`).
  - `recorder.py`: Self-contained Python 3.13 verified Recorder raw chunk & `mcp-export` reader (with USD-M `usdm`/`um_perpetual` aliases and `orderbook`->`rest_observations` snapshot routing), `AggTradeDeduplicator`, single-source Spot/USD-M `L2SequenceBridge.step_sequence` (strict `U<=lastUpdateId<=u` & `pu==prev_u` on USD-M), `resolve_event_ts_ns` (USD-M `T`-first alignment), and Nautilus converters.
  - `vision.py`: Fixed Binance Vision parser (2025-01-01+ Spot microsecond normalization, strict boolean parsing, coverage registry).
  - `live.py`: `grpc.aio` `BmdDataClient` with Fail-Fast capability preflight, multi-stream ingestion (`BOOK_TICKER`, `AGG_TRADE`, `DIFF_DEPTH`/`depth_baseline`, `MARK_PRICE`/funding, sparse `LIQUIDATION`/`REFERENCE_DATA` exempt from watchdog `STALE`), and `GAP`/`STALE` `InstrumentStatus(HALT)` gating (retained for low-frequency research/parity).
  - `tonic_live.py` + `rust_bmd_tonic/`: M-NT2.5 Route A Rust `tonic` + `prost` + `PyO3` (`bmd_tonic_ext`) gateway client prototype with Rust-side `AggTrade` dedup & immediate GAP `CLEAR`/`HALT` (archived benchmark prototype; M-NT2.5 locked **Route B/B+**, Nautilus native Rust `BinanceDataClientFactory` + 300s slow REST poller, for `M-NT3`/`M-NT4` production high-freq ingestion).
  - `spot_runner.py`: Strict Spot F1 `BacktestEngine` & `LiveNode (Sandbox)` (`BookType.L1_MBP`, `liquidity_consumption=True`, `bar_execution=False`), cash/inflight reservation guard, two-stage UID reconciliation, and causality/delay verification.
  - `patterns.py`: M-NT2 verified strategy patterns — `MakerLimitPostOnlyStrategy` (with explicit `MAKER_QUEUE_BOUNDARY_NOTICE` requiring `HftBacktest` for queue-sensitive Maker alpha), `CrossAssetFactorStrategy` + `TradingAllowlistGuard`, `L2MicrostructureStrategy`, and `MultiTimescaleHybridStrategy`.
  - `ml_bridge.py`: Causal `FeatureEngine` + `ModelBundle` Nautilus bridge (`Purged+Embargoed Walk-Forward` enforcing `embargo_ns`, contiguous healthy-epoch labeling, `<1ms` inference, fail-closed `ts_init <= trained_until_ns` cutoff).
- `bq_feed`: Unified typed events (`events.py`), Recorder Raw/normalized deterministic replay (`replay.py`, including Vision microsecond & strict bool fixes), Gateway live gRPC client with `enabled_streams` Fail-Fast + `STALE` watchdog (`live.py`), and capability matrix / Recorder-vs-Gateway parity checker (`parity.py`).
- `bq_feature`: Pure causal stateful feature engine (`update(state, event)` + `on_health`) with dual clocks, R1/R7/N5/R9/R6/OFI/Microprice/causal K-lines, and `features.parquet` export.
- `bq_model`: Purged + Embargoed Walk-Forward trainer (enforcing `embargo_ns` across `walk_forward_only=True` folds) and `<1ms` inference bundles (`models/<model_id>/`).
- `bq_mcp`: Local stdio MCP server (6 tools, `<64 KiB` responses, AST + causality + parity guard).
- Frozen legacy modules (per 2026-11-25 D1/D9 decision, preserved for regression/reference only): `bq_backtest`, `bq_signal`, `bq_order`.
